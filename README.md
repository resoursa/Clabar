# Клабар

Записник для гри в клабар: рахунок, бейти, висяки, хто здає, і коротка шпаргалка з правилами. Працює офлайн і встановлюється на телефон як застосунок (PWA). Інтерфейс українською та англійською.

A scorekeeper PWA for the card game Klabar (Klabor / Odesa debertz). It works offline and has Ukrainian and English UI.

## Що вміє

- Двоє, троє або пара на пару; гра до 301 / 501 / 1001.
- Очки за взятки: останнє поле заповнюється само (разом 162).
- Комбінації: терц, полтина, белла, лижі.
- Сам рахує бейт (очки йдуть суперникові), висяк (очки висять до наступної роздачі) і штраф за третій бейт.
- Будь-яку роздачу можна виправити або видалити, рахунок перерахується.
- Дані зберігаються в браузері на пристрої.

## Запуск локально

```sh
python3 -m http.server 8765
# http://localhost:8765
```

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
Сайт буде на `https://<user>.github.io/Clabar/`.

Після змін у файлах збільште `VERSION` у `sw.js`, щоб телефони отримали оновлення.
